# 🎯 AL - 日常生活助手

一个现代化的日常生活管理应用，帮助你更高效地管理任务、日程、支出���养成良好习惯。

## ✨ 功能特性

### 📋 待办事项管理
- 创建和管理日常任务
- 支持多个分类（工作、生活、健康、学习）
- 标记任务完成状态
- 实时显示任务进度

### 📅 日程安排
- 创建和管理日程事件
- 支持设置时间和地点
- 按时间自动排序
- 一目了然的日程视图

### 💰 支出记录
- 记录日常支出
- 多个支出分类
- 统计今日、本月支出和平均每天支出
- 支出数据分析

### 🎯 习惯追踪
- 创建并追踪养成的习惯
- 支持每日、每周、每月频率
- 显示完成次数和连续天数
- 鼓励持续养成好习惯

### 📊 数据统计
- 任务完成率统计
- 习惯坚持情况分析
- 支出情况统计
- 日程规划总览

### 🌙 主题切换
- 支持亮色和深色主题
- 根据系统偏好自动选择
- 主题偏好本地保存

### 📱 响应式设计
- 适配各种屏幕尺寸
- 移动端友好的界面
- 触摸友好的交互设计

## 🚀 快速开始

### 安装

1. 克隆或下载项目文件
```bash
git clone https://github.com/HuMax1212/al.git
cd al
```

2. 使用任何现代浏览器打开 `index.html`
```bash
# 使用 Python 启动本地服务器（可选）
python -m http.server 8000

# 或使用 Node.js
npx http-server
```

3. 在浏览器中访问 `http://localhost:8000`

## 📖 使用指南

### 待办事项
1. 在输入框中输入任务
2. 选择任务分类
3. 点击"添加"按钮
4. 完成任务时勾选复选框
5. 需要删除时点击"删除"按钮

### 日程安排
1. 输入事件标题
2. 选择时间（可选地点）
3. 点击"添加日程"
4. 日程会按时间自动排序

### 支出记录
1. 输入支出金额
2. 选择支出分类
3. 可选添加备注
4. 点击"记录"
5. 系统自动统计各类支出数据

### 习惯追踪
1. 输入习惯名称
2. 选择习惯频率
3. 点击"创建习惯"
4. 每日完成时点击"今日完成"
5. 系统追踪连续完成天数

### 数据导出
- 进入"统计"标签页
- 点击"导出数据"下载 JSON 格式数据
- 可用于备份或数据分析

## 🛠️ 技术栈

- **前端**: HTML5, CSS3, Vanilla JavaScript
- **存储**: LocalStorage（本地浏览器存储）
- **主题**: CSS 变量实现深色/浅色切换
- **响应式**: 现代 CSS Grid 和 Flexbox

## 📊 数据存储

所有数据存储在浏览器的 LocalStorage 中：
- 不需要后端服务器
- 数据完全私有，存储在本地
- 清除浏览器数据时会清除应用数据
- 支持导出功能进行备份

## 🎨 自定义

### 修改颜色主题

编辑 `styles.css` 中的 CSS 变量：

```css
:root {
    --primary: #6366f1;           /* 主色 */
    --success: #10b981;            /* 成功色 */
    --warning: #f59e0b;            /* 警告色 */
    --danger: #ef4444;             /* 危险色 */
    /* ... 其他变量 */
}
```

### 添加新功能

1. 在 `index.html` 中添加新的 HTML 结构
2. 在 `styles.css` 中添加样式
3. 在 `app.js` 中的 `ALApp` 类中添加相应方法
